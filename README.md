# BoT Arena

สนามซ้อมส่วนตัวสำหรับการ์ดเกม **Battle of Talingchan** — จัดเด็คก่อนซื้อจริง ดวลกับบอท/เพื่อน และให้ "ชิเอล" (Claude) ช่วยวิเคราะห์

- เว็บส่วนตัว ใช้ได้เฉพาะบัญชีที่เจ้าของอนุมัติ (`noindex`)
- **ไม่มีระบบซื้อขาย เติมเงิน หรือหารายได้ใดๆ** ทั้งสิ้น
- ข้อมูลและภาพการ์ดโหลดสดจากเว็บทางการ [bottcg.com](https://bottcg.com/cards) ไม่ได้เก็บสำเนาไว้ใน repo นี้ ลิขสิทธิ์การ์ด ภาพ และชื่อเกมเป็นของเจ้าของเกม (PASULOL / LION HOUSE) ใช้ส่วนตัวโดยได้รับอนุญาตจากทีมงาน
- กติกาอ้างอิง Rule Book 3.2 · การ์ดทุกใบ (1140 ใบที่มีข้อความ) ทำงานอัตโนมัติ · มีโหมดสอนเล่นทีละขั้น
- ซ้อมได้หลายแบบ: บอทสามระดับ ซ้อมมือเดียวกับหุ่นซ้อม ย้อนตาได้ รีเพลย์และหน้าสรุปหลังจบเกม ห้องทดลองจำลองเกม
- โจทย์ปริศนา "ชนะให้ได้ในเทิร์นนี้" ที่ค้นจากเกมจริงระหว่างบอทและตรวจด้วยการค้นทุกทางป้องกัน (`tools/puzzles`) เก็บแค่เลขการ์ดกับตำแหน่ง
- ดวลกับเพื่อนแบบออนไลน์ ดูเกมของเพื่อนได้ (ไม่เห็นมือทั้งสองฝั่ง) อันดับในกลุ่มเพื่อนแบบ Elo ทัวร์นาเมนต์พบกันหมดที่เจ้าของจัดได้ และแจ้งเตือนเมื่อถึงตาเรา (ขณะแอปเปิดค้างไว้)
- ความสำเร็จได้จากการเล่นเท่านั้น ปลดล็อคอวตาร 3 มิติ (ช้างน้อย ลูกพญานาค แมววิเชียรมาศ เสือน้อย) สีผ้าปูโต๊ะ และวงอัญเชิญ (ไม่มีอะไรให้ซื้อ)
- ภารกิจประจำวันวันละ 3 ข้อ (ทุกคนได้ข้อเดียวกัน คิดจากประวัติการเล่นเอง) สะสมดาวปลดล็อคของตกแต่ง

## โครงสร้าง
- Static site บน GitHub Pages (ES modules ไม่มี build step)
- Firebase Auth (Google) + Firestore — กฎความปลอดภัยอยู่ใน `firestore.rules`
- three.js r128 + GSAP สำหรับสนาม 3 มิติ
- ชิเอลเรียก Claude API ด้วย key ของผู้ใช้เอง เก็บเฉพาะใน localStorage ของเบราว์เซอร์

## เครดิตทรัพยากรฟรี
- Particle textures: [Kenney Particle Pack](https://kenney.nl/assets/particle-pack) (CC0)
- ฟอนต์: Chakra Petch, IBM Plex Sans Thai (Google Fonts, OFL)
- สนามดวลลายรดน้ำ (ลงรักปิดทอง ย่อมุม ลายประจำยาม) วาดด้วยโค้ดใน `js/arena3d.js`
- โต๊ะไม้สัก แสงเทียนที่อบลงเนื้อไม้ เชิงเทียนทองเหลือง พวงมาลัยมะลิ ขันน้ำ และห้องโถงที่ทองสะท้อน สร้างเองด้วย Blender จากสคริปต์ใน `tools/env` (ไฟล์ผลลัพธ์อยู่ใน `assets/env`)
- เพลงประกอบแนวปี่พาทย์ (บันไดเสียงไทย 7 เสียง ระนาด ฆ้องวง ขลุ่ย ฉิ่งฉาบ กลอง) และเสียงเอฟเฟกต์ทั้งหมดสังเคราะห์สดด้วย Web Audio ใน `js/music.js` และ `js/sfx.js` ไม่มีไฟล์เสียงจากภายนอก
